## 1. 2040 서울도시기본계획 (서울플랜)

발표: 2023.02 / 서울시 최상위 법정 도시계획

### 중심지 체계
- **3도심**: 서울도심(한양도성), 여의도·영등포, 강남
- **7광역중심**: 용산, 청량리·왕십리, 창동·상계, 상암·수색, 마곡, 가산·대림, 잠실
- **12지역중심**: 동대문, 성수, 망우, 미아, 연신내·불광, 신촌, 마포·공덕, 목동, 봉천, 사당·이수, 수서·문정, 천호·길동

### 4대 혁신축
- **청년첨단 혁신축** (동북권): 홍릉→청량리→창동·상계. 바이오·의료·ICT
- **감성문화 혁신축** (서북권): 상암 DMC 중심 미디어·R&D
- **국제경쟁 혁신축** (서남권): 광화문→서울역→용산→여의도·영등포. 금융·핀테크
- **미래융합 혁신축** (동남권): 강남→양재→수서·문정. AI·로봇

### 7대 핵심 키워드
- 보행일상권, 수변공간 활용, 기반시설 입체화, 중심지 기능 혁신, 미래교통(GTX·UAM), 탄소중립, Beyond Zoning Seoul(용도지역 유연화)

## 2. 강북전성시대 2.0

발표: 2026.03 / 서울시 균형발전기획관 / 총 16조

### 재원
- 서울시 10조 + 국비 2.4조 + 민자 3.6조
- 사전협상 공공기여 현금 비중 30→70%, 강북전성시대기금 신설

### 10대 성장거점
1. **창동·상계 S-DBC** — 서울디지털바이오시티, 800개 기업 유치 (동북·핵심)
2. **서울아레나** — 2.8만석 K-POP 공연장, 2027 개관 (동북)
3. **DMC 랜드마크** — 미래산업·미디어 거점 (서북)
4. **서부면허시험장 이전지** — 첨단산업 거점 (서북)
5. **삼표레미콘 부지** — 79층 초고층 복합, 유니콘 창업허브 (사전협상)
6. **동서울터미널** — 환승센터·업무·상업 복합 현대화 (사전협상)
7. **광운대역 물류부지** — 업무·상업·주거 복합거점 (사전협상)
8. **세운지구** — 13.6만㎡ 녹지, 직주락 도시 (도심)
9. **서울역 북부역세권** — 2029 완성, 39층 5개동, MICE (도심)
10. **용산서울코어** — 용산정비창 국제업무지구 (도심)

### 핵심 교통
- 강북횡단 지하고속도로: 내부순환~북부간선 20.5km, 왕복 6차로
- 동부간선도로 지하화: 월계IC~대치IC 15.4km
- 강북횡단선(철도), 동북선(2027 개통), 우이신설연장선(2032)
- 강북 노후 지하철 20개역 환경개선 1.0조

### 핵심 제도
- **성장거점형 복합개발**: 도심·광역중심·환승역세권 500m 내, 비주거 50%+ → 용적률 최대 **1,300%**
- **성장잠재권 활성화**: 폭 35m+ 간선도로변, 공시지가 60% 이하 자치구 → 공공기여 30%까지 인하

### 관련 지역 키워드
노원구, 도봉구, 강북구, 성북구, 중랑구, 동대문구, 광진구, 성동구, 용산구, 종로구, 중구, 은평구, 서대문구, 마포구, 창동, 상계, 미아, 광운대, 청량리, 왕십리, 상암, 수색

## 3. 서남권 대개조 2.0

발표: 2026.03.05 / 총 7.3조 (시비 4.7조 + 민간 1.8조 + 국비 0.8조)

### 대상 자치구
양천구, 강서구, 구로구, 금천구, 영등포구, 동작구, 관악구

### 핵심 제도
- 준공업지역 용적률: **250% → 400%**
- 정비유형: 4가지 → 2가지 (산업복합형/주거복합형, 공장 10% 기준)
- 복합개발 면적 제한 폐지 (1만㎡ 제한 삭제)
- 산업혁신구역 지정 (용도·밀도 규제 자유)

### 산업 거점
- **마곡산단**: 피지컬 AI 산업 거점, 복합용지 전환
- **G밸리**: 교학사·마리오아울렛 특별계획구역 복합개발
- **온수산단**: 첨단제조업 재구조화
- **서부트럭터미널**: 10.4만㎡ 도시첨단물류단지 (1.9조)
- **금천 공군부대**: 컴팩트시티
- **관악S밸리**: 낙성대 벤처창업 거점

### 핵심 교통
- 남부순환 지하도로: 개화동~신림동 15km (강남↔강서 70분→40분)
- 국회 지하차도: 신월IC~국회의사당 7.6km
- 서부간선도로 4→5차로 확장
- 신림봉천터널 (강남순환로 연결)
- 도시철도: 강북횡단선, 목동선, 서부선, 난곡선

### 주택
2030년까지 7.3만호 착공. 모아타운 37개소 (서울 81개소 중 37%).

### 녹지
서울초록길 48.4km, 봉천천·도림천 생태하천 복원

### 관련 지역 키워드
양천구, 강서구, 구로구, 금천구, 영등포구, 동작구, 관악구, 마곡, 가산, 대림, 구로디지털단지, G밸리, 온수, 신정동, 목동, 여의도, 봉천, 신림, 난곡

## 4. 2040 서울플랜 세부 내용 (해설자료 발췌)

### 7대 목표

| 구분 | 목표 | 핵심 내용 |
|------|------|-----------|
| 삶의 질 | 보행일상권 조성 | 주거·일자리·여가·상업 도보 30분 내 |
| 삶의 질 | 수변 중심 공간 재편 | 한강·4대 지천을 생활 중심으로 |
| 삶의 질 | 기반시설 입체화 | 지상철도 지하화·데크 활용 새 공간 창출 |
| 도시경쟁력 | 중심지 기능 혁신 | 3도심·7광역중심 고도화, 신성장 산업 연계 |
| 도시경쟁력 | 미래교통 인프라 구축 | GTX·UAM·자율주행버스 도입 |
| 가치·방향 | 탄소중립 안전도시 | 기후변화 대응, 2050 탄소중립 |
| 가치·방향 | 도시계획 대전환 | Beyond Zoning Seoul, 정성적 계획지원 체계 |

### Beyond Zoning Seoul (용도지역 유연화)
- 기존 경직된 용도지역제를 유연하게 운용 → **주거·업무·여가 등 다기능 복합지역** 조성
- 지자체별 허용 범위 내에서 용도·밀도 규정 완화
- 상업지역 주거비율 상향, 준주거지역 용적률 상향, 준공업지역 공동주택 용적률 완화 추진

### 5개 권역 생활권 체계

| 권역 | 포함 자치구 | 발전 방향 |
|------|------------|-----------|
| 도심권 | 종로·중·용산 | "첨단과 전통이 공존하는 미래 도심 재탄생" |
| 동북권 | 성동·광진·동대문·성북·강북·도봉·노원·중랑 | "신성장·교통경제거점으로의 도약을 통한 균형발전" |
| 서북권 | 은평·서대문·마포 | 감성문화·미디어·창조산업 중심 |
| 서남권 | 강서·양천·구로·금천·영등포·동작·관악 | 산업혁신·주거복합 대개조 |
| 동남권 | 서초·강남·송파·강동 | AI·로봇·미래융합 산업 거점 |

- 지역생활권: 인구 10만 명 내외, 3~5개동 단위 (서울 전역 100여개 이상)

### 도심권 4+1축 (서울도심 세부)
- **국가중심축** (광화문~시청): 역사·문화 기반 도심 비즈니스 허브
- **역사문화관광축** (인사동~명동): 쇠퇴 상권 활성화, 관광상업허브
- **남북녹지축** (창덕궁~한강): 종묘~퇴계로 혁신거점, 녹지생태도심
- **복합문화축** (대학로~장충단공원): DDP 중심 패션·뷰티 산업
- **글로벌상업축** (광화문~동대문): 청계천 동서 연결, 상업지역 통합

### 주요 중심지별 특화 기능
- **용산 광역중심**: 정비창 부지 → 국제업무지구(글로벌기업·MICE·복합용도). GTX·KTX·UAM 모빌리티 허브
- **청량리·왕십리 광역중심**: 동북권 최대 교통 결절지. GTX-C, 동북선 신설. 역세권·유휴부지 복합개발
- **창동·상계 광역중심**: 미래신산업+문화예술 기반 수도권 동북부 경제중심지 (S-DBC)
- **강남 도심**: 3+1 직결체계(서울도심-여의도-강남-용산). AI·로봇·미래융합 산업

### 6대 융복합 산업거점
| 거점 | 특화 분야 |
|------|-----------|
| 홍릉 | 바이오·의료 |
| 마곡 | R&D |
| G밸리 (구로·금천) | IoT·제조혁신 |
| DMC (상암) | 문화콘텐츠·미디어 |
| 양재·개포 | R&D·AI·빅데이터 |
| 마포·여의도 | 블록체인·핀테크 |

**신성장 산업거점** (미래 잠재력): 광운대, 구로, 김포공항, 수서·문정

### 광역교통 인프라
**GTX 노선**
- GTX-A: 파주 운정~삼성 (광화문·시청역 추가 정차 검토)
- GTX-B: 송도~마석 (종로3가·동대문역 신설 검토)
- GTX-C: 양주 덕정~수원 (삼성~청량리 추가 환승역 검토)

**신규 철도 (계획)**
- 강북횡단선, 동북선(2027), 우이신설연장선(2032), 서부선, 목동선, 난곡선, 신구로선

**미래교통**
- UAM 터미널: 단계적 확충 (용산-삼성·잠실-창동·상계 등 12개 거점)
- 자율주행버스: 서북권-강남권·서남권-강북권·서부권-동부권 3개 축

### 기반시설 입체화 (지상철도 지하화)
- 서울 내 지상철도 101.2km, 차량기지 4.6㎢ → 단계적 지하화·데크화
- 주요 대상: 경부선(서울역~용산~영등포~금천), 경인선, 경의선(수색~홍대), 경춘선·중앙선(망우)
- 지하화 후 상부: 선형 여가공간·복합개발거점으로 전환

### 수변공간 활성화
- 4대 지천: **중랑천·홍제천·안양천·탄천** — 수변특화거점 + 배후주거지 접근성 강화
- 한강: 업무·상업·관광 중심 수변도시 (여의도·이촌·한남·반포·압구정·옥수·성수)
- 정비사업 시 한강 연계 의무화 (수변으로 경계 허물기)

### 주택·정비 방향
- 저이용·유휴지, 역세권 활용 다양한 주택 공급
- 준공업지역 공동주택 용적률 완화 (공공기여 조건)
- 도심 노후 주택: 노원(33.9%), 양천(29.7%), 용산(28.8%) — 소규모 정비·개보수 지원
- 광역중심·역세권 도시정비형 재개발: 주거+생활SOC+생활편의 복합개발

## 정책 간 연결고리

| 연결 | 내용 |
|------|------|
| 서울플랜 → 강북전성시대 | 서울플랜의 '청년첨단 혁신축'이 S-DBC로 구체화. 중심지 체계(광역중심 창동·상계)에 용적률 1,300% 적용. |
| 서울플랜 → 서남권 대개조 | 서울플랜의 광역중심(마곡, 가산·대림)이 산업 거점으로 특화. Beyond Zoning이 준공업지역 규제완화로 현실화. |
| 강북 ↔ 서남권 | '비강남권 대개조' 양대 축. 강북 16조/용적률 1,300% vs 서남권 7.3조/용적률 400%. 교통→산업→주거→녹지 동일 전략 구조. |
| 공통 | 지하도로(강북 20.5km, 서남권 15km), 도시철도 신설, 사전협상 활용, 산업 자족성 확보 |
